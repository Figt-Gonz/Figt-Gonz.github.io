选 API 的最短路径

做任务、不需要结果 → launch
并发计算、需要结果 → async + await
顺序执行、换执行上下文 → withContext
一组任务共同成功或失败 → coroutineScope
直接子任务失败互不拖累 → supervisorScope
一串异步值 → Flow；协程之间传递值 → Channel
